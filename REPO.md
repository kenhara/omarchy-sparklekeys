# Sparklekeys — repo notes

GitHub: `https://github.com/kenhara/omarchy-sparklekeys`

Letter Hunt typing tutor for Omarchy. Stars, Closet, pack-driven characters.
Unicorn default; dragon stub. Local only — no network.

```sh
omarchy plugin add https://github.com/kenhara/omarchy-sparklekeys.git --enable
omarchy bar move kenhara.sparklekeys --section right
```

Progress (keep — this is earned stars, not a cache):
`~/.local/share/sparklekeys/progress.json`
